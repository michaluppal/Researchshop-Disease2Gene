\subsection{Research Workflow}

To retrieve the appropriate publications, users can either create their own query or use the AI Query Assistant to generate one. Furthermore, the Extraction Columns feature also enables users to customize the data and add information extracted from the selected publications (Figure~\ref{fig:query_setup}).

For example in Figure~\ref{fig:app_workflow_screens}, the query was \texttt{(KRAS AND Poland AND lung cancer) AND 2025:2026[dp]}, where \texttt{dp} is PubMed's date-of-publication field tag. Table~\ref{tab:demo_output_trace} reports the complete recorded run. The History view's \emph{Genes found} value sums unique genes within each paper, whereas the Results view deduplicates gene labels across the final output. Figure~\ref{fig:app_workflow_screens} also shows an exported KRAS G12C row with separate fields and source citations. This example demonstrates output structure and traceability, not extraction accuracy.
The recorded duration is retained as run provenance only. The model and complete runtime configuration were not preserved with the supplied workbook, so this value is not compared with the controlled Windows Subsystem for Linux (WSL) experiment in Section~\ref{sec:impact}.

\subsection{Audit Artifacts}

Each run includes the final tables and companion audit files. For every candidate, these files record its source, normalization, validation result, matched citation, and any exclusion reason. Reviewers can therefore check an accepted row against the article text without repeating the LLM call.

\subsection{Figure and Table Handling}

Many genomics papers encode primary findings in figures, tables, and supplementary files rather than in prose. ResearchShop parses JATS XML from PMC and Europe PMC, extracts structured table text, collects figure captions and image URL candidates, and passes table/caption context into evidence validation. When figure analysis is enabled and images are downloadable, a multimodal Gemini model is used for analysis.

ResearchShop downloads the papers and the files around them itself: PubMed records, open-access full text from PMC and Europe PMC, citation data, tables, figure captions, and supplementary files. An existing article parser is used only for a few pieces of the paper’s XML, such as the body paragraphs and the figure metadata.
